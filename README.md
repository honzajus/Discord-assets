# Discord Assets

Sbírka Discord **avatar decorations** a **nameplates**, hostovaná přes GitHub Pages.

| Složka | Obsah | Formát |
| --- | --- | --- |
| [`avatar_decoration/`](avatar_decoration) | dekorace avataru | `.png` |
| [`nameplates/`](nameplates) | animované nameplates | `.webm` |

## Použití

Soubory jsou dostupné přímo přes GitHub Pages:

```
https://honzajus.github.io/Discord-assets/avatar_decoration/<nazev>.png
https://honzajus.github.io/Discord-assets/nameplates/<nazev>.webm
```

Příklad:

```html
<img src="https://honzajus.github.io/Discord-assets/avatar_decoration/cozy_cat.png" alt="Cozy Cat">

<video src="https://honzajus.github.io/Discord-assets/nameplates/aurora.webm" autoplay loop muted playsinline></video>
```

Názvy se speciálními znaky (`'`, `(`, `)`, mezery) je potřeba v URL zakódovat, např. `andy's_room_clouds.webm` → `andy%27s_room_clouds.webm`.

## Poznámka

Všechny assety patří Discordu a příslušným vlastníkům. Tento repozitář slouží jen jako hosting pro moji stránku.
